Como Publicar este Projeto no GitHub (GitHub Pages)

  1. Crie um novo repositório no GitHub (ex: aura-motors-landing).
  2. Salve este código em um arquivo chamado index.html no seu computador.
  3. Faça o upload (ou envie via Git no terminal) do arquivo index.html para o repositório criado.
  4. No seu repositório no GitHub, vá em Settings (Configurações) > Pages.
  5. Na seção Build and deployment, escolha a branch main (ou master) e clique em Save.
  6. Pronto! Em instantes o GitHub fornecerá o link público para o seu site no ar.
